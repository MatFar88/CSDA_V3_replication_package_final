# Scope and validation - CSDA V3

REPORT targets the CSDA submission version dated 23 October 2026. The archived 41-cell study, FINAL32 fixed-parameter comparison and aggregate banking tables are integrated. FINAL32 merged rows are checked against eight workers and three original summaries. No estimator is refitted by REPORT.

The author supplied passing MATLAB SELFTEST/CHECK/REPORT logs on Windows for the immediately preceding package generation. The V3 build validation reruns Python tests, saved-result reporting and package-integrity checks for the manuscript-relevant FRESH/FINAL32/banking evidence.

A FULL rerun remains optional and expensive; it is not represented as completed by REPORT. Confidential banking microdata are outside the public package.
